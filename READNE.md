# Online Library Management System (C++)

## Course
BSD 122 – Object-Oriented Programming I

## Assignment
Assignment 1: Online Library Management System

---

## Project Description
This project implements a simple Online Library Management System using C++ and Object-Oriented Programming (OOP) principles.  
The system models real-world library operations such as managing books, users, and borrowing or returning books.

---

## Features
- Add books to the library
- Register users
- Borrow and return books
- Prevent borrowing of already borrowed books
- Basic validation of invalid operations

---

## Classes Used

### Book
Represents a book in the library.
- Stores book ID, title, author, and borrowing status

### User
Represents a library member.
- Stores user ID, name, and borrowed books

### Library
Manages books and users.
- Handles borrowing and returning logic

---

## Object-Oriented Concepts Applied
- Encapsulation
- Abstraction
- Modularity
- Single Responsibility Principle
